# Sistema de Avaliação Acadêmica

Uma aplicação web moderna e responsiva desenvolvida para automatizar o cálculo de médias escolares e fornecer diagnósticos acadêmicos em tempo real.

---

## Funcionalidades

- **Cálculo Automático de Média:** Processamento imediato das notas informadas.
- **Validação de Dados:** Bloqueio de entradas inválidas (notas fora do intervalo de 0 a 10 ou campos vazios).
- **Diagnóstico em Tempo Real:** 
  - **Aprovado:** Média igual ou superior a 7.0.
  - **Recuperação:** Média entre 5.0 e 6.9 (com cálculo dinâmico de quantos pontos faltam para a aprovação).
  - **Reprovado:** Média inferior a 5.0.
- **Interface Responsiva & Acessível:** Layout estilizado com CSS moderno (Inter Font, gradientes, sombras e suporte a leitores de tela).
- **Redefinição de Estado:** Botão para limpar campos e reiniciar a consulta com foco automático no primeiro input.

---

## Tecnologias Utilizadas

- **HTML5:** Estruturação semântica (`<main>`, `<header>`, `<form>`).
- **CSS3:** Customização visual, CSS Flexbox, Microinterações e estilização de estados via classes.
- **JavaScript (ES6+):** Manipulação de DOM (`classList`), gestão de eventos e lógica condicional.
